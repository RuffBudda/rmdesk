# rmdesk Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A PySide6 desktop app for a reMarkable 2 with three features: file transfer, live screen share (goMarkableStream client), and adding traced images/text as ink to an existing notebook page.

**Architecture:** A pure-Python core (`connection`, `library`, `notebook`, `compose`, `stream`, `safety`) behind a small `Device` interface (run commands, read/write files), which can be faked in tests. The Qt `ui` package is the only one that imports PySide6. Notebook edits append new blocks (a new `rmdesk` layer and its lines) to the page's existing v6 block list, so original blocks are written back unchanged.

**Tech Stack:** Python 3.14, PySide6, paramiko, keyring, opencv, numpy, requests, websocket-client, rmscene 0.8.0, rmc 0.3.0, Hershey-Fonts, pytest, pytest-qt.

**Spec:** `docs/superpowers/specs/2026-11-03-rmdesk-design.md`

## Global Constraints

- Only `src/rmdesk/ui/` may import PySide6. Everything else must be importable without Qt.
- USB address `10.11.99.1`; SSH user `root`, port 22.
- Tablet data dir: `/home/root/.local/share/remarkable/xochitl`.
- Local paths: config `~/.config/rmdesk/config.toml`, backups `~/.local/share/rmdesk/backups/<notebook-uuid>/<timestamp>/`, log `~/.local/state/rmdesk/rmdesk.log`, venv `~/.local/share/rmdesk/venv` (created with `--system-site-packages`).
- Keyring service name `rmdesk`, username = the tablet serial from `/sys/devices/soc0/serial_number` (never the IP or "usb"). Before the serial is known (first connect), the password is held in memory and saved once the serial has been read.
- Page coordinates (rM2): width 1404, height 1872; v6 x runs from -702 to 702, y from 0 to 1872.
- New layer label: `rmdesk`. Temp page suffix: `.rmdesk-tmp`. Present window title: `rmdesk — Present`.
- Never delete documents permanently: trash = `"parent": "trash"` in `.metadata`.
- Backup retention: delete backups older than 30 days, but always keep the 5 newest per notebook.
- `xochitl` restart timeout: 30 s.
- Compose disabled message (exact): `This firmware isn't tested yet. Writing to notebooks is disabled.`
- Theme: background `#0b0b0b`, surface `#161616`, text `#e8e8e8`, accent `#d01f2f`, accent hover `#ff3344`.
- Each commit message ends with `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>`.

## Review Focus

1. **Pages with several layers or text already on them:** adding items must keep every existing layer, stroke and text item, and the new layer must stack on top. Pinned by `test_append_keeps_multilayer_page` (Task 9).
2. **Connection drops mid-send:** a page must never end up half-written; the original stays or the backup is restored. Pinned by `test_upload_failure_restores` and `test_restart_timeout_restores` (Task 12).
3. **Very detailed images** (a photo dropped in by mistake): tracing must cap output at `MAX_POINTS = 20000` total points and report the cap rather than freezing or writing a huge page. Pinned by `test_trace_caps_points` (Task 11).
4. **Characters the ink font doesn't have** (emoji, non-Latin letters): skip them, report them, don't crash. Pinned by `test_ink_text_unknown_glyphs` (Task 11).
5. **Unusual file names on upload** (spaces, non-ASCII, `.PDF` uppercase): accept them, with the visible name taken from the file name without its extension. Pinned by `test_upload_odd_names` (Task 5).

`append_layer` ID allocation and block order. The library has no tree-to-blocks writer, so we append:
```
author = 1 (the local-device author from AuthorIdsBlock; add {1: uuid4()} if absent)
next = max(id.part2 for every CrdtId in all blocks where id.part1 == author) + 1   # walk dataclass fields recursively
layer_id = CrdtId(author, next++)
blocks += SceneTreeBlock(tree_id=layer_id, node_id=CrdtId(0,0), is_update=True, parent_id=CrdtId(0,1))
blocks += TreeNodeBlock(si.Group(node_id=layer_id, label=LwwValue(CrdtId(author,next++), label), visible=LwwValue(CrdtId(author,next++), True)))
last_layer = the right-most existing SceneGroupItemBlock under CrdtId(0,1)
blocks += SceneGroupItemBlock(parent_id=CrdtId(0,1), item=CrdtSequenceItem(item_id=CrdtId(author,next++), left_id=last_layer.item.item_id or CrdtId(0,0), right_id=CrdtId(0,0), deleted_length=0, value=layer_id))
prev = CrdtId(0,0)
for line in lines:
    iid = CrdtId(author, next++)
    blocks += SceneLineItemBlock(parent_id=layer_id, item=CrdtSequenceItem(iid, prev, CrdtId(0,0), 0, line))
    prev = iid
```
Insert the `SceneTreeBlock` + `TreeNodeBlock` + `SceneGroupItemBlock` right after the last existing `SceneGroupItemBlock`, and the `SceneLineItemBlock`s at the end of the block list. `PageInfoBlock` is left unchanged.
