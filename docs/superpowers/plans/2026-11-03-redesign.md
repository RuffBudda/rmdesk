# UI Redesign Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Restyle rmdesk to the user-approved redesign (calm dark surface, one red accent, icon sidebar with a device pill, card-based Files and Device, picture-first Screen with a docked Compose toolbar, friendly states) without changing behaviour.

**Architecture:** One theme module (`ui/theme.py`: tokens → generated QSS, dynamic-property variants) plus small reusable widgets (`ui/widgets/`: NavButton, DevicePill, Chip, Card, Banner, ToggleSwitch, Segmented, EmptyState, ConfirmSheet). Each view is rebuilt on these, keeping every existing signal/slot, worker and safety path. Custom painting only where the design table says so (document card delegate, toggle switch, sheet scrim).

**Tech Stack:** PySide6, QSS, Qt SVG icons.

**Spec (design source):** the approved mock-up (not in this repository) (`Spec.dc.html` = style spec + QSS starter + Qt table; `Main/Screen-View/Screen-Compose/Device/States.dc.html` = screens). Read the relevant artboard before each task.

## Global Constraints

- Tokens (exact): bg `#0B0B0B`, surface-1 `#141414`, surface-2 `#1C1C1C`, surface-3 `#262626`, line `#2B2B2B`, accent `#D01F2F`, accent-hover `#E23443`, accent-text `#FF6B73`, text `#EDEDED`, text-2 `#B0B0B0`, text-3 `#8F8F8F`, ok `#4CC764`, warn `#E8AB3C`, paper `#ECEBE6`.
- Type: font family "Inter", fallback system UI (Inter is not installed — do not install packages); mono "JetBrains Mono" (installed as the Nerd variant). Sizes: display 22/600, title 18/600, heading 15/600 (dialog 17), body 13/400–500, small 12, overline 11/600 caps.
- Spacing 4-pt scale; view padding 20, card padding 18, grid gap 14; buttons/inputs 36 tall (32 dense), nav rows 40, status bar 30, sidebar 208.
- Radii: 6 thumbs, 8 buttons/inputs, 10 pill/banners, 12 doc cards, 14 cards, 16 dialogs/sheets, full chips.
- Icons: 24-grid outline, 1.8 stroke, round caps (Lucide style), 16 px in UI, 20 in cards; bundled as SVG files under `src/rmdesk/ui/icons/` (hand-written paths or Lucide, ISC licence file included), recoloured with the text colour.
- One `variant="primary"` button per screen: Files → Upload, Screen → Send to tablet (compose) / Present (view), Device → Connect.
- Behaviour unchanged: every existing test keeps passing (update only selectors/texts that the redesign changes, never safety assertions). No change to `safety`, `notebook`, `compose` core.
- Ctrl+1/2/3 switch Files/Screen/Device.
- The confirm stays modal in effect (worker waits), shown as an in-window sheet; its texts and 60 s timeout unchanged.
- pytest with `timeout 300`/`600`; bounded waits; never `git stash`; commit only your paths.
- Commit messages end with a blank line + `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>`.

## Review Focus

1. Narrow tiled window (e.g. 700 px wide): toolbars wrap, nothing clipped — `test_narrow_window_no_clipping` per view.
2. Keyboard-only use: every action reachable by Tab, focus ring visible — `test_tab_order` per view.
3. Text contrast ≥ 4.5:1 for text-3 on surface-1 — `test_token_contrast` (Task 1).
4. Dynamic property changes re-polish (chip state, button variant) — `test_chip_state_repolish` (Task 1).
5. Confirm sheet while the window is closed / view hidden still answers No — `test_sheet_cancel_on_close` (Task 4).
